# Oh My Director · 暮光电影馆

根据「Oh My Director：从灵感到电影」品牌参考与仓库现有工作流设计的原创品牌 UI。纯 HTML、CSS、JavaScript，无构建依赖，所有影像均保存在本目录，可离线打开。

## 打开

双击 `index.html`，或在仓库根目录启动：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory ui
```

访问 `http://127.0.0.1:4173`。本地文件与 HTTP 地址属于不同存储环境；持续创作建议固定使用同一个地址。

## 界面

- 品牌首页：电影主视觉、五阶段入口、项目卡片、创作之旅。
- 我的片场：搜索、收藏筛选、新建与导入 Markdown / TXT 剧本。
- 剧本：编辑、真实场次提取、500ms 自动保存、Markdown 导出。
- 视觉 DNA：风格关键词选取、概念情绪板、色板与风格草案导出。
- 美术：角色、场景、道具三类概念档案与设定导出。
- 分镜：四个概念镜头、景别、运镜与时长，分镜资料导出。
- 预演：按时长播放 20 秒无声概念图序列、暂停、重播与 JSON 导出。
- 品牌手册：字标、配色、字体、组件和设计原则。访问 `#brand`。

## 品牌语言

**核心命题：每个世界，都从一个念头开始。**

「暮光电影馆」以深青黑色承接影像，以香槟金引导行动，以暖白宋体承接中文的文学性。取景框包围 D，角落的一颗星代表被看见的灵感；字标里的斜体 My 代表创作者自己的签名。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--ink` | `#0B1213` | 页面画布、导航 |
| `--surface` | `#111B1D` | 编辑面板 |
| `--surface-raised` | `#172225` | 层次与组件 |
| `--gold` | `#E8BD87` | 主行动、当前阶段 |
| `--paper` | `#F5EEE2` | 标题与正文 |
| `--muted` | `#91A09F` | 元信息 |
| `--teal` | `#73948E` | 保存状态 |

标题采用 Georgia / 系统中文宋体，操作信息采用 Segoe UI / 微软雅黑。无外部字体请求。1px 分隔线、4–8px 圆角、16:9 与宽银幕影像贯穿页面；动效为短距离入场、轻微抬升与影像缓动，并尊重 `prefers-reduced-motion`。

响应式布局覆盖桌面、平板和手机；窄屏保留阶段导航，将侧栏收为工具栏。

## 实现范围

这是可交互的品牌与界面原型。项目、剧本文本、收藏、风格选择和推进阶段通过 localStorage 保存在当前浏览器。JSON 导出包含项目、风格草案与示例镜头；目前没有 JSON 回导功能。

情绪板、美术档案与分镜使用统一的原创示例素材，新建项目不会自动生成专属资产。概念图播放不等于视频生成，也不等于 Blender 白膜；实际生产仍通过仓库中的四个技能与相关工具完成。没有登录、云同步、生成 API 或后台服务。
